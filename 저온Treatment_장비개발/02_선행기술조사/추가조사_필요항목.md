## 1. 🔴 경쟁 방식 비교 (플라즈마 외 저온 Treatment 포함)

요구사양의 "플라즈마로 할 것인가"를 결정하려면 대체 기술 비교가 먼저 필요하다.

| 방식 | 조사 포인트 | 보유 |
|---|---|---|
| 라디칼 산화 / ISSG (In-situ steam generation) | 온도(보통 고온) 대비 막질 기준점(Baseline)으로 사용 | ✗ |
| 마이크로파 슬롯 안테나 플라즈마 (SWP/SPA 계열) | 저전자온도 → 손상 적음 주장의 근거 데이터 | 특허 1건 |
| 디커플드 플라즈마 질화 (DPN) + 후속 어닐(PNA) | 산업 표준 질화 방식, 온도·N 프로파일 | ✗ |
| UV / 오존(O₃) / 광산화 | 무손상 산화, 성장 속도 한계 | 논문 1건 |
| 고압 수소/중수소 어닐 (HPA) | 저온 결함 치유, 장비 형태(고압 챔버) | ✗ |
| 마이크로파 어닐 / 레이저 어닐 | 표면만 가열하는 방식의 열예산 | ✗ |
| 저온 ALD + 인시투 플라즈마 처리 | 증착·처리 통합 가능성 | ✗ |

## 2. 🔴 플라즈마 손상·오염 데이터

저온 플라즈마 장비의 가장 큰 리스크 항목인데 보유 자료에 정량 데이터가 거의 없다.

- 이온 충격·차징(Charging) 손상: 안테나 TEG, Dit 증가량, 게이트 누설 영향
- 진공자외선(VUV) 광자 손상: 리모트/Grid 구조에서 차단 효과
- 금속 오염: 석영·Al₂O₃·Y₂O₃ 부품에서 나오는 Al, Y, Fe, Na 등의 수준
- 수소 혼입: NH₃/H₂ 사용 시 막 내 H 함량과 신뢰성(BTI) 영향
- **찾을 자료:** 플라즈마 유발 손상(PID) 리뷰 논문, 리모트 vs 직접 플라즈마 비교 논문

## 3. 🔴 고종횡비(High aspect ratio) 구조 등각성

3D NAND/DRAM/GAA 적용 시 핵심 지표.

- 라디칼 재결합(Recombination) 계수: 표면 재질·온도별 O·N·H 라디칼 손실
- 압력·체류시간에 따른 바닥/상부 두께비 데이터
- 관련 보유: KR20240121901A(이중 압력), US20140273309A1(라디칼 수명) → 수치 데이터 보강 필요
- **찾을 자료:** 라디칼 산화 등각성 논문, 트렌치/GAA 시트 사이 IL 형성 사례

## 3-1. 🔴 AMAT Producer Viva (2026-11-12 추가)

P1 플랫폼(리모트 소스 + 이온 필터 + H/N/O)과 가장 가까운 상용 장비. 공개 자료에 정량 정보가 없다.

- **라디칼 전달 구조 특허 찾기:** AMAT가 "특허로 보호된 구조"라고 밝힘. 리모트 소스, 이온 필터, 순수 라디칼 전달 관련 AMAT 최근 출원을 검색 → 회피 설계 포인트 확인
- **공정 조건:** 온도, 압력, 가스(수소 외 사용 여부). 학회 발표(VLSI, IEDM)나 AMAT 기술 발표에서 확인
- **GAA 채널 처리 메커니즘:** 수소 라디칼로 Si 표면이 평탄해지는 원리, 처리 후 IL 형성까지의 순서
- **구리 배선 용도:** Pyra 열처리와의 순서, 저항이 줄어드는 메커니즘
- **메모리 적용 사례:** 발표에서는 언급만 있음

## 4. 🟠 공정 메커니즘·모델링

- 저온 산화 동역학: Deal-Grove가 맞지 않는 초박막 영역, 라디칼 확산 모델
- 플라즈마 질화 시 N 프로파일(표면 vs 계면) 제어 인자
- 소스 모델링: 라디칼 플럭스, 전자온도, 이온 에너지 분포(IEDF) 측정·시뮬레이션 자료
- **활용:** `03_공정조건_Window` 수치 근거

## 6. 🟠 경쟁 장비·시장

- 주요 장비사 제품군과 공개 사양: 온도 범위, 소스 방식, Throughput (공개 브로셔·학회 발표 기준)
- 디바이스 업체 채택 사례: 학회(VLSI, IEDM) 발표에서 공정 언급 사례
- 가격·CoO: 공개 자료가 적어 "확인 불가" 가능성 높음 → 내부 정보로 보완

## 7. 🟠 특허 지형 / FTO

- 주요 출원인별 핵심 특허 군: 소스 구조, Grid, 저온 산화·질화 방법
- 보유 특허들의 패밀리·존속기간·권리범위(독립항) 정리 → 회피 설계 포인트
- 최근 3~5년 출원 동향 (KR/US/CN/JP)
- **주의:** 법적 판단은 변리사 검토 필요, 여기서는 기술적 정리만

## 8. ⚪ 평가·분석 방법

- 초박막(<2 nm) 두께·조성 측정 한계: Ellipsometry vs XPS vs TEM
- N·H 깊이 분포: ARXPS, SIMS 해상도 한계
- 전기적 평가 TEG 구성 (C-V, I-V, TDDB, BTI)
