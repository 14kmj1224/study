# Visual guidelines

Choose visuals from the evidence, not from a fixed quota.

## Preferred mappings

| Question | Visual |
|---|---|
| What components exist and how are they connected? | Block or sectional schematic |
| What happens in what order? | Process flow |
| What triggers a control response? | Decision flow |
| How do conditions or alternatives differ? | Comparison matrix |
| What does the measured evidence show? | Bar, line, or scatter chart |

## Construction rules

- Use Korean labels and give the English term on first appearance when useful.
- Keep source identifiers such as component numbers, figure numbers, claim numbers, values, and units unchanged.
- Add `원문 기반 재구성 - 축척 아님` to reconstructed technical schematics.
- Put the source PDF page or figure in a visible footer or caption.
- Use a consistent palette: navy for normal flow, cyan for plasma or energy, amber for warning, and red for stop or abnormality.
- Use arrows only when direction or dependency is established by the source.
- Use a chart baseline and scale that do not exaggerate differences.
- For thresholds, distinguish example settings from universal requirements.
- Ensure the diagram remains readable at fit-to-width in a Word document.

Before delivery, compare each visual against the evidence table and inspect the rendered output for missing glyphs, clipping, overlap, and unreadable labels.
